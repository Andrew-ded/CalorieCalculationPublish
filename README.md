# CalorieCalculationPublish

Публикационный репозиторий приложения **CalorieCalculation2** — здесь публикуются только релизные APK и ассеты.

Исходный код: https://github.com/Andrew-ded/CalorieCalculation2

## Установка

1. Скачать [`app-release-v1.0.apk`](app-release-v1.0.apk).
2. На устройстве разрешить установку из неизвестных источников для выбранного приложения (Браузер / Файлы).
3. Открыть APK и подтвердить установку.

## Обновления

Приложение само проверяет последний релиз этого репозитория через GitHub Releases API и предлагает обновиться.

## Содержимое

| Файл | Назначение |
|---|---|
| `app-release-v1.0.apk` | Сборка приложения, версия 1.0 |
| `model.ptl` | Веса MobileViT-XXS (PyTorch Mobile Lite) для распознавания блюд |
| `classes.json` | Соответствие индексов модели → ключам блюд |
| `food.json` | Справочник блюд: русское название, ккал/100 г |
