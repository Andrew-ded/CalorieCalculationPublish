# CalorieCalculationPublish

Публикационный репозиторий приложения **CalorieCalculation2** — здесь публикуются только релизные APK.

Исходный код: https://github.com/Andrew-ded/CalorieCalculation2

## Установка

1. Скачать последнюю версию APK (см. таблицу ниже).
2. На устройстве разрешить установку из неизвестных источников для выбранного приложения (Браузер / Файлы).
3. Открыть APK и подтвердить установку.

## Обновления

Приложение само проверяет последний релиз этого репозитория через GitHub Releases API и предлагает обновиться.

## Содержимое

| Файл | Назначение |
|---|---|
| `app-release-v1.3.apk` | **Актуальная** сборка — версия 1.3 |
| `app-release-v1.2.apk` | Сборка версии 1.2 |
| `app-release-v1.1.apk` | Сборка версии 1.1 (кнопка профиля в шапке) |
| `app-release-v1.0.apk` | Сборка версии 1.0 |

> Веса ML-модели (`model.ptl`), словари (`classes.json`, `food.json`) зашиты внутрь APK — отдельно скачивать их не нужно.
